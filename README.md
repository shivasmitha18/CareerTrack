
CareerTrack is an AI-powered Job Application and Career Management Platform built with Java and Spring Boot.

## Features

- User registration and login
- JWT-based authentication
- Secure password encryption
- Job application management
- Application status tracking
- Search and filtering
- Pagination
- Interview date tracking
- Application statistics
- Input validation
- MySQL database integration
- RESTful APIs

## Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Spring Security
- JWT
- Maven
- Postman
- Git & GitHub

## Project Structure

The project follows a layered architecture:

- Controller
- Service
- Repository
- Entity
- DTO
- Configuration
- Exception Handling

## API

The backend provides REST APIs for managing users and job applications.
